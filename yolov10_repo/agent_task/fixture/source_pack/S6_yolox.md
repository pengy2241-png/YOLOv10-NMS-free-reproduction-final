# Core contribution
YOLOX changes YOLO to an anchor-free detector, introduces a decoupled head and uses the SimOTA label assignment strategy.

# Evidence
YOLOX-L reaches 50.0% AP at 68.9 FPS on Tesla V100 in the reported setting.

# Limitation
It is a technical report and its evidence is concentrated on COCO detection performance.
